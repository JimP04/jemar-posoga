# Jemar Posoga Portfolio Website

## Files
- `index.html` — website content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and small interactions
- `assets/Jemar-Posoga-CV.pdf` — downloadable resume

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Extract this ZIP file.
2. Upload the contents of this folder (not the enclosing ZIP) to the root of your GitHub repository.
3. Make sure `index.html`, `style.css`, `script.js`, and the `assets` folder are at the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select your `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

The resume download button points to `assets/Jemar-Posoga-CV.pdf`. Keep that file path and name unchanged unless you also update the links in `index.html`.

## Before publishing
This portfolio uses the contact details and career information from the CV you provided. Review them before making the repository public. GitHub Pages websites are publicly accessible.
